# CUPB Thesis LaTeX Skill

中国石油大学（北京）本科生毕业设计(论文) LaTeX 排版系统。
严格遵循《中国石油大学（北京）本科生毕业设计（论文）写作指南》格式要求。

## 工具定位

工具文件打包在插件 `tools/` 目录中。执行时先定位：

- **项目本地** (优先): 检查当前目录下是否有 `sample/skill.py`
- **插件缓存** (通用): `~/.claude/plugins/cache/cupb-tools/cupb-thesis/tools/skill.py`

## 使用方式

用户调用时传入的参数为: `$ARGUMENTS`

```bash
# 定位工具路径 (二选一)
# 优先用项目本地的 sample/skill.py，否则用插件缓存中的 tools/skill.py

# Markdown → .tex + PDF (一键)
python <tools>/skill.py <论文.md> --compile \
  --title "题目" --author "姓名" --studentid "学号" \
  --college "学院" --major "专业" --adviser "指导教师" \
  --finishdate "20xx年x月" \
  --keywords "关键词1；关键词2" \
  --en-keywords "keyword1; keyword2" \
  --entitle "English Title"

# 仅生成 .tex
python <tools>/skill.py <论文.md> --title "题目" --author "姓名" ...

# 仅编译已有 .tex
python <tools>/skill.py <论文.tex> --compile-only

# 编译后清理临时文件
python <tools>/skill.py <论文.md> --compile --clean
```

## 文档结构 (自动生成)

封面 → 声明 → 中文摘要 → 英文摘要 → 目录 → 前言 → 正文(第1章~结论) → 参考文献 → 附录 → 致谢

## 格式要点

| 项目 | 要求 |
|------|------|
| 纸张 | A4, 页边距 3.0cm, 左侧装订 1.0cm |
| 正文 | 宋体小四号 (12pt), 多倍行距 1.25 |
| 一级标题 | 黑体三号居中 (第1章, 第2章…) |
| 二级标题 | 黑体四号 (1.1, 1.2…) |
| 三级标题 | 黑体小四号 (1.1.1…) |
| 页眉 | 黑体五号, 奇/偶页不同 |
| 页码 | 前置罗马数字, 正文阿拉伯数字 |
| 参考文献 | GB/T 7714-2005 顺序编码制 |

## Markdown 预处理 — 自动层级识别与重构

**重要**: 在执行转换前，必须对原始 Markdown 文件进行智能预处理，自动识别文档结构并添加正确的 `#`/`##`/`###` 层级标记。大多数原始论文 Markdown 没有标准标题标记，标题只是独立的短文本行。

### 识别规则

按以下优先级逐行扫描全文，为每行分配层级：

#### 1. 论文标题 (第一个 `#`)
- 文件第一行非空内容
- 不以数字序号、括号编号开头
- 通常是完整的长句（含冒号、破折号等）
- 赋予 `# ` 前缀

#### 2. 章标题 (一级 `#`)
匹配以下特征的行（独立成行、前后有空行、行长短）：
- 典型关键词: `引言`, `前言`, `文献综述`, `结论`, `建议`, `参考文献`, `致谢`, `附录`, `主要符号表`
- 含"研究"的短标题: `研究背景`, `研究内容`, `研究方法`, `实证分析`, `理论分析`
- 以"第X章"开头
- 行长度一般 ≤ 20 字符
- 末尾无标点符号（或仅有"}"、"]"等闭合符号）
- 赋予 `# ` 前缀

#### 3. 节标题 (二级 `##`)
在章标题之下的子标题：
- 行长度适中（一般 4-30 字符）
- 末尾通常无句号/逗号等停顿标点
- 位于章标题和正文段落之间
- 常见模式: `研究背景与意义`, `国内外研究现状`, `XXX效应研究`, `对XXX的建议`
- 中文编号开头: `第一，`, `其一，` 等开头的独立短行
- 赋予 `## ` 前缀

#### 4. 子节标题 (三级 `###`)
在节标题之下的更细粒度标题：
- 行长度较短
- 常见模式: `投资者情绪与乐观偏差`, `心理账户与XXX`, `实证结论` 等
- 赋予 `### ` 前缀

#### 5. 参考文献条目
- 以 `[1]`, `[2]` 或 `[J]`, `[M]`, `[N]` 等文献类型标记结尾
- 或包含 `（20xx）`, `[J].` 等学术引用格式特征
- 保留原样，不添加 `#`

#### 6. 正文段落
- 长句（> 50 字符）
- 或以 `随着`, `在`, `根据`, `然而`, `因此`, `此外` 等连接词开头的句子
- 不添加 `#`，保留原样

### 预处理执行流程

1. **读取原始文件** — 用 Read 工具读入完整内容
2. **分行扫描** — 逐行分析每行的特征（长度、位置、关键词、标点、上下文）
3. **分配层级** — 按上述规则给每行标记层级（title/h1/h2/h3/body/reference）
4. **输出重构文件** — 将添加了 `#` 标记的内容写入**新文件** `<原文件名>_structured.md`（保留原文件不做修改）
5. **验证** — 快速检查层级树的合理性：每个 h2 有父 h1，无跳跃层级

### 边界情况处理

- **歧义行**: 若某行既可作 h2 又可作 h3，默认取更高级别（h2）
- **连续短行**: 若连续出现多个疑似标题的短行，按层级递进处理
- **致谢/附录/参考文献**: 即使长度较短也始终作为一级标题（`#`）
- **表格/代码块**: 跳过，保持原样
- **空行**: 保留原样，用于分隔段落

## 执行步骤

1. 定位工具目录：先找项目 `sample/skill.py`，没有则用 `~/.claude/plugins/cache/cupb-tools/cupb-thesis/tools/skill.py`
2. 确认 Markdown 文件存在
3. **【新增】Markdown 预处理**: 按上述"Markdown 预处理"规则，智能分析并重构文档层级，生成 `<原名>_structured.md`
4. 收集元信息 (题目、姓名、学号等)，未提供的用占位符
5. 对**预处理后的** `_structured.md` 运行转换脚本生成 .tex
6. 若 `--compile`，执行 xelatex ×3 编译，辅助文件进 `build/`
7. 报告结果

## 编译要求

- XeLaTeX (TeX Live / MacTeX 2024+)
- 中文字体: Windows 自带 SimSun/SimHei, macOS 自带 Songti SC/Heiti SC
- 可选: `tlmgr install gbt7714` (GB/T 7714 参考文献格式)
